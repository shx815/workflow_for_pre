2. FlashAttention 的底层加速与显存优化原理是什么，Tiling 和 Recomputation 是如何协同工作的？
3. 详细解释 RoPE（旋转位置编码）的数学原理，为什么它具备优秀的外推能力与相对位置感知特性？
4. KV Cache 的显存占用计算公式是什么，PageAttention 如何从操作系统分页维度解决显存碎片化问题？
5. LayerNorm 与 RMSNorm 的计算差异是什么，Pre-LN 与 Post-LN 在训练深层 Transformer 时各有什么优缺点与收敛表现？
6. Grouped-query Attention（GQA）与 Multi-Query Attention（MQA）的核心设计思想及对推理吞吐量的影响是什么？
7. MoE（混合专家模型）中 Router 的路由机制与负载均衡损失（Auxiliary Loss）是如何设计的，如何避免专家坍塌？
8. 为什么大语言模型在训练和推理过程中普遍采用 SwiGLU 替代传统的 ReLU/GELU 激活函数？

10. LORA 的低秩分解数学逻辑是什么，前向传播与权重合并公式如何推导，初始化时为什么矩阵 B 要设为全 0？
11. QLORA 的核心改进是什么，NF4（4-bit NormalFloat）量化与双重量化（Double Quantization）的具体实现机制是什么？
12. 详细对比 P-Tuning v2、Prefix-Tuning 与 Prompt-Tuning 在参数插入位置与可训练参数量上的本质差异。

14. 训练大模型时发生 Loss Spike（损失骤增）或梯度爆炸的常见原因有哪些，有哪些工业界落地的排查与恢复手段？
15. Megatron-LM 中的张量并行（Tensor Parallelism）在 MLP 层和 Attention 层分别是如何做切分与 All-Reduce 通信的？

## 参考答案要点

以下为原文提供的思路，未补入外部答案：

原文仅详解第 4 题；其余 15 题的答案，原文未提供。

- 每个 token 的 KV Cache 字节数按原文公式计算：`2 × Layers × Hidden_Size × Precision_Bytes`，其中第一个 `2` 对应 K 和 V。
- 原文以 Llama-7B 的 32 层、4096 维度、FP16 为例，计算每 token 为 524,288 字节，称约 0.5 MB；batch size 为 32、序列长度为 1024 时，称约需 16 GB。
- 原文要求从连续存储的碎片化和预分配浪费切入，类比操作系统虚拟内存，解释 Block 与 Mapping Table。
- 图片 6–7 补充：把序列的 KV Cache 划分为固定大小的 Blocks，由 Block Table 将逻辑连续的序列映射到物理非连续块；生成 token 时动态分配，当前块满后再申请下一块。
- 图片 7–8 还提及并行采样、束搜索时共享前缀 KV Cache，以及 Copy-on-write；原文未提供实现代码。
