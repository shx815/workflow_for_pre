# 字节算法岗二面：手撕因果掩码自注意力

关联主题：[[by-topic/Transformer|Transformer]] · [[by-topic/Self-Attention|Self-Attention]] · [[by-topic/KV-Cache|KV Cache]]

## 具体问题

1. 给定形状为 `L×d` 的 `Q`、`K`、`V`，实现并计算 `softmax(QKᵀ/√d + M)V`；其中 `M` 的严格上三角为 `−∞`，对角线及以下为 `0`。
2. 为什么 Decoder 要遮住未来位置？
3. 为什么掩码要加在 attention score 上，而不能把权重乘 `0`，或在 softmax 后把上三角清零？
4. 为了数值稳定而减去行最大值时，为什么最大值要在加掩码之后计算？
5. 该实现的时间复杂度和空间复杂度是多少？
6. 原文提到的追问方向：多头注意力、padding mask、KV Cache。

## 参考答案要点

- 第 `i` 个位置只能看见 `0..i`；未来位置的 score 加 `−∞` 后，`exp(−∞)=0`，等价于只在可见位置上做 softmax。
- Decoder 训练时会一次输入整句，第 `i` 个位置需要预测第 `i+1` 个 token；如果能看到未来 token，就会泄漏答案，而推理阶段并不存在这些未来信息。
- 将未来权重直接乘 `0` 是错误的：若在 softmax 前乘零，`exp(0)=1`，未来位置仍会分到权重；若在 softmax 后清零，每行权重和不再为 `1`。
- 原文给出的样例中，第 `0` 行正确输出为 `[1,2]`；错误掩码会得到 `[2.4895,3.4895]`。
- 时间复杂度为 `O(L²d)`，空间复杂度为 `O(L²+Ld)`。
- 多头、padding 和 KV Cache 仅被列为追问方向，当前原始描述没有给出具体答案。

## 关键细节

- 场景：字节算法岗二面；原文称搜广推和多模态搜索二面都出现过。
- 核心考点不是普通自注意力，而是掩码加入的位置、softmax 归一化和数值稳定处理。
- 给定样例：`Q=K=[[1,0],[0,1],[1,1]]`，`V=[[1,2],[3,4],[5,6]]`。

> 题目：给 L×d 的 Q、K、V，算 softmax(QKᵀ/√d+M)V。M 的严格上三角是 −∞，对角线及以下是 0，第 i 个位置只能看见 0 到 i。掩码加在分数上，再按行 softmax：未来位置 exp(−∞)=0。乘 0 后 exp(0)=1，未来位置照样分到权重。时间 O(L²d)，空间 O(L²+Ld)。
